# داشبورد نمایشی مدیریت منابع آب زیرزمینی سمنان

داشبورد «شبکه هوشمند ابتکار ویستا» یک رابط کاربری کاملاً راست‌به‌چپ، واکنش‌گرا و فارسی است که صرفاً برای نمایش قابلیت‌های پایش و پیش‌بینی منابع آب زیرزمینی استان سمنان توسعه داده شده است. این پروژه کاملاً فرانت‌اند بوده و تمام داده‌ها به صورت ساختگی در مرورگر تولید می‌شوند؛ بنابراین می‌توان آن را بدون وابستگی به سرور یا پایگاه‌داده اجرا کرد.

## فناوری‌ها و پیکربندی
- **React 18 + TypeScript** بر پایه Vite برای توسعه سریع
- **Tailwind CSS** برای سبک‌های ماژولار و تم رنگی آبی/سبز متناسب با حوزه آب
- **Recharts** برای ترسیم نمودارهای خطی، ستونی و نمایش عدم قطعیت
- فونت فارسی **Vazirmatn** و حالت **RTL** در سطح ریشه برنامه
- داده‌های ساختگی متمرکز در `src/data/mockData.ts` شامل سری‌های زمانی، چاه‌ها، سناریوها و گزارش‌ها

## قابلیت‌ها و تعاملات کلیدی
- **داشبورد نمای کلی** با چهار کارت KPI، نمودار دوخطی «مشاهدات» و «پیش‌بینی AI»، به‌روزرسانی‌های شبه‌بلادرنگ و لیست هشدارهای اخیر.
- **نمای نقشه چاه‌ها** شامل فیلتر دشت، نوع چاه، نمایش لایه بحرانی، راهنمای رنگ و پاپ‌آپ جزئیات هر چاه.
- **نمودارهای زمانی** با فیلتر چاه، بازه زمانی و نوع شاخص (سطح آب، بارش، برداشت) به‌همراه کارت‌های آماری پایین نمودار.
- **پیش‌بینی هوش مصنوعی** با انتخاب مدل (LSTM یا Random Forest)، نمایش خط عدم قطعیت و جدول شاخص‌های ارزیابی (RMSE، R²، افق پیش‌بینی).
- **تحلیل سناریوها** با اسلایدرهای برداشت/بارش، انتخاب افق زمانی، دکمه اجرای سناریو، نمودار مقایسه‌ای و جدول خروجی.
- **جدول چاه‌های مشاهده‌ای** دارای جستجو، مرتب‌سازی، صفحه‌بندی و هایلایت وضعیت بحرانی.
- **مدیریت گزارش‌ها** با لیست گزارش‌های ساختگی، دکمه «ایجاد گزارش جدید» و دراور پیکربندی گزارش همراه با پیام موفقیت نمایشی.
- **تنظیمات و کاربران** شامل جدول کاربران، دکمه‌های ویرایش/غیرفعال‌سازی و سوییچ‌های تنظیمات سامانه.

## پیش‌نیازها
1. **Node.js 18 یا جدیدتر** (شامل npm)
2. **دسترسی به اینترنت** برای نصب وابستگی‌ها (تنها در مرحله `npm install`)
3. Git (اختیاری، در صورت کلون کردن مخزن)

> نکته: اگر به دلیل محدودیت‌های شبکه سازمانی امکان نصب بسته‌ها فراهم نیست، می‌توانید پوشه `node_modules` را از محیطی دیگر منتقل کنید یا از رجیستری آفلاین استفاده نمایید.

## نصب و اجرای پروژه در ویندوز
1. **نصب Node.js**: آخرین نسخه LTS را از [nodejs.org](https://nodejs.org) دانلود و نصب کنید. حین نصب، گزینه «Automatically install the necessary tools» را فعال کنید تا npm نیز نصب شود.
2. **دریافت سورس**:
   ```powershell
   git clone https://example.com/basement-water.git
   cd basement-water
   ```
   یا فایل ZIP را دانلود و استخراج کنید، سپس به پوشه پروژه بروید.
3. **نصب وابستگی‌ها**:
   ```powershell
   npm install
   ```
4. **اجرای محیط توسعه**:
   ```powershell
   npm run dev
   ```
   آدرس پیش‌فرض `http://localhost:5173` است. مرورگر خود را باز کرده و داشبورد را مشاهده کنید.
5. **ساخت نسخه تولیدی** (اختیاری):
   ```powershell
   npm run build
   npm run preview
   ```
   این دستور فایل‌های بهینه‌شده را در پوشه `dist` تولید می‌کند و سپس یک سرور محلی فقط خواندنی راه‌اندازی می‌کند.

## نصب و اجرای پروژه در اوبونتو / لینوکس
1. **به‌روزرسانی بسته‌ها**:
   ```bash
   sudo apt update && sudo apt upgrade -y
   ```
2. **نصب Node.js 18 از مخزن رسمی**:
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
   sudo apt install -y nodejs build-essential
   ```
   (در صورت نیاز می‌توانید از nvm استفاده کنید.)
3. **دریافت سورس**:
   ```bash
   git clone https://example.com/basement-water.git
   cd basement-water
   ```
4. **نصب وابستگی‌ها**:
   ```bash
   npm install
   ```
5. **اجرای محیط توسعه**:
   ```bash
   npm run dev -- --host
   ```
   گزینه `--host` اجازه می‌دهد از دستگاه‌های دیگر شبکه محلی نیز به برنامه دسترسی داشته باشید. آدرس پیش‌فرض `http://localhost:5173` است.
6. **ساخت و پیش‌نمایش نسخه تولیدی**:
   ```bash
   npm run build
   npm run preview -- --host
   ```

## اسکریپت‌های npm
| دستور | توضیح |
|-------|-------|
| `npm run dev` | اجرای سرور توسعه Vite با قابلیت HMR |
| `npm run build` | کامپایل TypeScript و ساخت بسته تولیدی در `dist/` |
| `npm run preview` | سرو کردن خروجی تولیدی برای بررسی نهایی |

## سفارشی‌سازی و توسعه بیشتر
- برای افزودن داده‌های ساختگی جدید، از الگوهای موجود در `src/data/mockData.ts` پیروی کنید. تمامی نماها داده‌ها را از این فایل دریافت می‌کنند.
- رنگ‌ها و تایپوگرافی‌ها در `tailwind.config.js` تعریف شده‌اند؛ می‌توانید پالت سازمانی خود را اضافه کنید.
- جهت استفاده از نقشه واقعی، می‌توان `MapView` را با کتابخانه‌هایی مانند `react-leaflet` جایگزین کرد؛ فقط کافی است داده‌های ساختگی موجود را به مختصات واقعی متصل نمایید.
- اگر قصد دارید داشبورد را با API واقعی متصل کنید، کافی است لایه‌های `useEffect` فعلی را با درخواست‌های `fetch` یا `axios` جایگزین کنید و مدیریت حالت را به ابزارهایی مثل React Query بسپارید.

## مشکلات متداول
- **خطای دسترسی به رجیستری npm**: اطمینان حاصل کنید که شبکه شما پورت‌های `443/80` را مسدود نکرده باشد. در صورت نیاز از پروکسی سازمانی در npm (`npm config set proxy ...`) استفاده کنید.
- **فونت فارسی نمایش داده نمی‌شود**: بررسی کنید که فایل `index.css` در ابتدای پروژه بارگذاری شده باشد و CDN فونت مسدود نشده باشد. در محیط‌های آفلاین می‌توانید فونت Vazirmatn را به صورت محلی میزبانی کنید.
- **نصب روی WSL**: مراحل اوبونتو را دنبال کرده و سپس از مرورگر ویندوز با آدرس `http://localhost:5173` متصل شوید.

این پروژه صرفاً برای ارائه‌ی نمایشی به «شرکت آب منطقه‌ای سمنان» طراحی شده و می‌توان آن را به عنوان نقطه شروع برای پیاده‌سازی نسخه‌ی عملیاتی با اتصال به سرویس‌های داده‌ای واقعی توسعه داد.
